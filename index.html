Individual controls project, system identification and PID design.

Given only measured input/output data from a dynamic system, the task was to work backward to a usable model. I used MATLAB system identification techniques to extract a state-space representation directly from the data, rather than deriving it from first principles.

From there I tuned a PID controller against that identified model and validated the closed-loop response against defined performance specifications — overshoot, settling time, steady-state error. It's a small project, but it's the same instinct that ran through my senior project: don't trust a model until you've checked it against something measured.
